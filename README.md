# strike-atlas

Городской монитор Киева: Обзор, Карта, Данные и Методика. Статический сайт
GitHub Pages; `city_data.json` генерируется в uk-monitor и копируется без правок.
Старые адреса traffic/food/dynamics сохраняют перенаправления.

Полные исследовательские отчёты доступны на самом сайте в `reports/` без
доступа к приватному backend. Сохранены принятые Markdown-тексты, четыре
статические HTML-страницы, подробные агрегаты, протокол и манифест источников.
`reports/provenance.json` фиксирует исходные blob SHA. Сырые ответы не публикуются.
Ранний разбор помечен как предыдущая версия, чтобы не смешивать базы сравнения.
Пересборка HTML: `python3 scripts/build_reports.py` (нужен Pandoc).

Проверка клиентского кода без зависимостей:

```bash
node --test tests/client.test.mjs
```

Проверки запускают настоящий код страниц с небольшим адаптером DOM: история,
фильтры, сценарии, пустая выборка, ошибки загрузки, безопасный вывод источников,
пригодность аренды для сравнения и качество наблюдений. Они не заменяют проверку
раскладки в браузере. Контракт модели и серверные тесты — в uk-monitor.

Повторяемые сценарии используют сохранённый срез в `tests/fixtures/city_data.json`.
Свежий `city_data.json` проверяется отдельно: новые наблюдения могут законно
изменить числа и состояния, сохраняя правила отображения.

## Тестовый обзор функций

`functions-test.html` — отдельный экран с календарём сведений по услугам,
источниками выбранного эпизода и учебной шкалой восстановления. Ссылка есть
в основном обзоре. По умолчанию открыт реальный реестр; учебные данные имеют
явное обозначение и отдельный переключатель. Общий процент активности города
не вычисляется: охват и объём использования ещё не измерены.

Шкалу `scenarios[].timeline` считает backend через рабочую модель на каждом
моменте публикации и устаревания. Контракт — `uk-monitor/docs/function_monitor.md`.
Клиентские регрессии используют сохранённый городской срез и отдельные
учебные `tests/fixtures/function_scenarios.json`; свежий снимок проверяется
отдельно. Старый снимок без шкалы и ошибка загрузки обозначаются явно.
`tests/layout.html` открывает этот же экран в настоящем iframe шириной 390
или 1140 CSS px для ручной проверки раскладки без изменения окна браузера.
