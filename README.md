# strike-atlas

Городской монитор Киева: Обзор, Карта, Данные и Методика. Статический сайт
GitHub Pages; `city_data.json` генерируется в uk-monitor и копируется без правок.
Старые адреса traffic/food/dynamics сохраняют перенаправления.

Проверка клиентского кода без зависимостей:

```bash
node --test tests/client.test.mjs
```

Проверки запускают настоящий код страниц с небольшим адаптером DOM: история,
фильтры, сценарии, пустая выборка, ошибки загрузки, безопасный вывод источников,
пригодность аренды для сравнения и качество наблюдений. Они не заменяют проверку
раскладки в браузере. Контракт модели и серверные тесты — в uk-monitor.

## Исправления 06.10.2026

- Контекст удара не подтверждает доступность услуги; главная говорит о сообщениях,
  а не о доказанных действующих ограничениях.
- История скрывает будущее восстановление, сутки считаются по времени Киева.
- Справочные точки аренды не дают изменений; база берётся из пригодного ряда.
- Пустая история и отсутствие сценариев не ломают обзор; ошибка загрузки видна.
- Неудачный обход табло УЗ виден рядом с последним успешным снимком.
- Снимок содержит исходную версию и контрольные суммы входов; копии сверяются
  по blob SHA. Учебные примеры вычисляет рабочая модель.
