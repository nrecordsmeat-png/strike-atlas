# Промпт для позиционного читателя

Запускается 2–3 раза, по одному на каждую позицию с оси спора текста, в чистом запуске без истории.
Позиции называются так, как их назвали бы сами сторонники, без оценочных слов.

---

```
Не используй никакие инструменты: ни поиск, ни файлы, ни память. Ответь по-русски, обычными словами.

Прочти текст так, как его прочтёт убеждённый сторонник [ПОЗИЦИЯ]. Не оценивай, кто прав.
Твоя задача — честно описать, как такой читатель понимает этот текст.

Ответь строго в формате:
СМЫСЛ ДЛЯ ЭТОГО ЧИТАТЕЛЯ: 1–2 предложения.
С ЧЕМ ТЕКСТ СПОРИТ: 1–2 предложения.
НА ЧТО ОН ОПРЁТСЯ: 2–4 мыслителя, исследователя или идеи, на которые такой читатель опёрся бы,
с одной строкой почему. Если не уверен в авторе или работе, пометь «не уверен».

ТЕКСТ:
[ТЕКСТ]
```

Имена из ответа «НА ЧТО ОН ОПРЁТСЯ» — только подсказка для поиска. В карту источник попадает
после проверки поиском, с пометкой `[официально]` или `[неверифицировано]`.
