Что меряем

После ударов по мостам (Южный закрыт с 1.10, Северный повреждён 3.10 — см. карту) главный транспортный вопрос Киева — цена переправы через Днепр. Индикатор: время в пути в минутах по трём фиксированным коридорам левый берег → правый (север: Троещина→Оболонь · центр: Дарница→центр · юг: Позняки→Лыбедская), снимаемое дважды в день в часы пик по данным TomTom с учётом живых пробок. Рост минут на коридоре = перегрузка оставшихся мостов; расползание между коридорами показывает, куда перетёк поток. Публикуются только минуты — без точных адресов точек замера.

Срез 04.10 — суббота, вечер: задержка от пробок по всем коридорам 0 минут — это и есть «пустая дорога», нижняя планка. Будничные пики — с понедельника 6.10; их превышение над этой планкой и станет рабочим сигналом.

Статус: в постройке. Публичный индекс пробок для Киева недоступен — города нет в TomTom Traffic Index (проверено зондом 04.10). Маршрутный замер строится через Routing API; ряд появится здесь с первых замеров.

Контекст мостов

До ударов у Киева шесть автомобильных переправ через Днепр. Южный мост закрыт после удара 1 октября (КРСН по опоре, версия UA), Северный (Московский) повреждён 3 октября — движение ограничено. Нагрузка перетекает на мост Патона, Дарницкий и Гавань: именно их пропускную способность и сторожит индикатор. Южный коридор при закрытом Южном мосте строится через Дарницкий — его текущие 13.5 мин и есть точка отсчёта объезда.
