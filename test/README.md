# Новый обзор города — тест

Изолированная версия нового обзора Киева и учёта восстановления услуг. Основные страницы карты не изменены. Для просмотра скачайте `overview.html` и откройте его в Edge, Chrome или Firefox; сервер и установка зависимостей не нужны. CSS, JavaScript и данные находятся в одном файле. Сеть нужна только для перехода по ссылке на первоисточник или основную карту.

Срез: **6 октября 2026, 08:08 по Киеву**. Сведения получены из сохранённых данных `uk-monitor` на `5c3bd0d`; последняя коллекция — 03:16 по Киеву. Новый автоматический сбор не подключён. Версия не служит оперативной сводкой.

## Что можно попробовать

- **Обзор**: шесть тем с последними замерами, датами и состоянием сведений.
- **Услуги и восстановление**: пять реальных эпизодов, фильтр услуги, история сообщений и первоисточники. Недельный отчёт об электричестве показан отдельно от эпизодов.
- **Дата просмотра**: 1–6 октября; сообщения и замеры после выбранной даты скрываются. Историческая дата означает конец дня по Киеву, текущая — время снимка.
- **Динамика**: отдельные сохранённые точки трёх транспортных коридоров, табло поездов и справочные точки аренды. Линии между транспортными точками не рисуются.
- **Данные и метод**: границы каждого вывода, покрытие выборки, неизвестное качество старых данных и условия учёта восстановления.
- **Тест сценариев**: шесть учебных примеров восстановления, резерва, частичной доступности, молчания, обещания и повтора сообщения. Они явно обозначены как вымышленные и не входят в историю Киева.

В реальной пилотной выборке нет сообщения о полном восстановлении пяти записанных эпизодов. Старые записи обозначены как неизвестные; это не утверждение о том, что ограничения продолжаются сейчас. Длительность без фактических времён источника не вычисляется. Недельное сообщение ДТЭК о 300 семьях города не превращается в долю доступности электричества или завершение конкретного перебоя.

## Сборка

Снимок создаёт `experiments/city_monitor/build_snapshot.py` в соответствующей тестовой ветке `uk-monitor`. Затем из корня `strike-atlas`:

```sh
python -m unittest discover -s test -p test_preview.py -v
python test/build_preview.py
node --test test/test_ui.mjs
```

`overview.template.html` — редактируемый исходник, `overview-data.json` — публичный снимок, `overview.html` — результат. После изменения шаблона или данных результат нужно пересобрать. Встраивание JSON экранирует символы, способные закрыть блок скрипта. Вывод сообщений в интерфейс экранируется; внешние ссылки проверяются на HTTPS.

## Проверка перед основной интеграцией

Автоматически проверены 26 сценариев модели/снимка, два теста безопасной сборки, синтаксис JavaScript и восемь проверок клиентского поведения через адаптер DOM в Node. Последние требуют Node.js 18+ и проверяют обработчики и вывод, но не имитируют браузерную вёрстку. Визуальный прогон в браузере среды недоступен: он блокирует локальные файлы. В основной сайт версия не развёрнута.

Для приёмки откройте файл на широком экране и при ширине 320–390 px; проверьте все пять разделов, переход из карточек, фильтры, смену даты, все шесть учебных примеров, табличное прокручивание и навигацию клавиатурой. Контрольные результаты: обещание и частичное восстановление оставляют эпизод открытым; молчание даёт неизвестное состояние и неизвестную длительность; повтор оставляет одно сообщение; учебное подтверждённое восстановление даёт 8 часов.

После приёмки можно отдельно решить вопрос автоматического обновления и размещения новой страницы на основном сайте. Эта ветка содержит только файлы каталога `test/` и не меняет его текущую публикацию.
